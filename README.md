An entry for make.fun's [Famous Last Words: The Funniest Epitaph](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406) bounty ($2, top ten places paid).

`main.py` writes one tombstone epitaph of famous last words — capped at 150 characters — to `entry.txt` in the output directory. Deterministic, no network, no randomness. The line is the whole entry.

> Here lies a man who asked "what could possibly go wrong?" This stone is the answer.

83 characters, within the 150-character cap. "What could possibly go wrong?" is the canonical famous last words; the twist is that the tombstone itself delivers the punchline, answering the question the dead man asked. One sentence, one image, one surprise — and it reads like something actually carved in stone.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
